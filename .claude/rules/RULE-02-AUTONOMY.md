# RULE-02 독립 실행 & 공통 금지

## 원칙
- **무상태**: 컨텍스트는 파일시스템만. 결정·보류·예외는 파일로 남긴다.
- **큐 기반**: 에이전트 간 직접 호출 금지. `specs/**` 생성/이동만.
- **No-op**: 입력 큐 비면 무해 종료.
- **비대화**: 사용자 질문·승인 요청 금지. 모호하면 `blocked/`.
- **Fail-fast**: 실패·충돌 → `blocked/` + `{slug}_reason.md`. 재시도 없음.
- **멱등**: 같은 입력 2회 = 같은 결과.

## 금지
- 자기 writer 영역 밖 생성/수정/삭제 (RULE-01 매트릭스).
- 다른 에이전트 큐 파일 내용 수정.
- `rm -rf`, `git reset --hard`, `git clean -f`, `git checkout -- .`, `git push --force*`, `git config`, `--no-verify`, `git commit --amend`.
- **자기가 만들지 않은 워킹트리 변경의 원복.** 경로를 지목한 `git checkout <path>` · `git restore <path>` · 백업 덮어쓰기 포함.
- **메인 워킹트리에서의 프로토타이핑.** 실험은 저장소 밖 격리 사본에서 (`git clone --local`).
- 민감 파일 (.env, *.pem, 자격증명).

> **금지 목록은 트리로 범위가 나뉘지 않는다.** scratchpad·격리 사본도 같다. 파괴는 "지금 어디에 있는가" 를 오인했을 때 일어나고, 그 순간 당사자는 자기가 예외 안에 있다고 믿는다. 삭제는 `mkdir -p <tmp>/trash && mv` 로 한다. **이 절을 근거로 자진 신고를 반복하지 않아도 된다** — 규약은 이미 판정했다.

- **예외**: `.claude/locks/**` 자가 생성 · `50.blocked/pipeline/` 쓰기 · `.claude/reports/<agent>.ndjson` **append**. lock 삭제는 운영자 전용.

### 교차 작업 파괴
워킹트리 원복은 **자기가 이 세션에서 만든 변경에 한정**한다. 파괴가 의심되면 **되살리려 하지 말고 즉시 중단**하고 `50.blocked/pipeline/` 에 박제한다 — 복구 시도가 2차 파괴가 된다.

**파괴 창과 겹친 측정은 무효다.** 재측정 전까지 그 `rc` 를 보고에 쓰지 않는다.

## 커밋 / 푸시

**커밋 단위는 세션이 아니라 큐 진행 1단위다.** 1단위 = 큐 경계 `mv` 1건 + 그 이동이 요구한 자기 영역 편집. 단위가 끝나면 다음으로 넘어가기 전에 커밋한다. 세션이 죽는 시점은 고를 수 없지만 죽었을 때 무엇이 남는지는 고를 수 있다.

**커밋 범위는 인덱스가 아니라 경로가 정한다.**

```
git add <paths>                          # 신규(미추적) 파일이 있을 때만
git commit -m "..." -- <paths>           # 경로는 반드시 맨 뒤
git show --name-only --format='' HEAD    # 자기 영역 밖 경로 0 확인
```

말미 pathspec 이 범위를 확정하므로 인덱스에 다른 writer 의 것이 있어도 섞이지 않는다. 자기 영역 밖 경로가 보이면 **중단하고 박제한다** — `--amend`·`reset` 으로 되돌리지 않는다.

- no-op tick 은 커밋하지 않는다. 스테이지 비면 생략 (빈 커밋 금지).
- **subject ≤ 72자.** tick 카운터·체인 수치 금지 (`.husky/commit-msg` 강제).
- 메시지: `{scope}({agent}): {요약}` — `{scope}` ∈ {spec, req, task, followup}. developer task 커밋은 `{type}: {title}` — `{type}` ∈ {feat, fix, refactor, chore, test, docs}. **운영자는 `operator: {요약}`** 이며 `meta` 경로와 에이전트 소유 경로를 한 커밋에 섞지 않는다.
- **push 는 developer 전용.** 그 외는 로컬 커밋까지.
- 훅 실패는 원인 수정·재시도. 우회 금지.

> 워크트리 분리는 답이 아니다 — 큐가 gitignored 라 새 워크트리에 존재하지 않는다. 공유가 필요한 것은 커밋과 큐뿐이고, 남는 위험(인덱스 공유)은 경로 지정으로 닫힌다.

## 파일 덮어쓰기
`>` 는 앞 명령이 실패해도 파일을 먼저 비운다. 원본을 덮어쓰는 자리에서는 **임시 파일에 쓰고 성공을 확인한 뒤 `mv`** 한다. 이력 파일(`ndjson`)은 **append 만** — 이미 쓴 줄은 틀렸어도 고치지 않는다.
