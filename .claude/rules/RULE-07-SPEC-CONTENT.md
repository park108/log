# RULE-07 Spec 콘텐츠

`30.spec/{blue,green}/**` 는 **시스템 불변식·계약** 만. 1회성 진단·조사·감사·incident patch 금지.

## 반려 시그널
- §동작 이 관측·측정·재현·TODO 나열 중심 → spec 아님.
- 특정 incident·릴리스·날짜에 귀속된 patch 제안 → spec 아님.
- **현재 이미 참이면서 위반 시 기존 게이트가 즉시 실패하는 보존 명제** → 중복, spec 아님.
- **위반해도 아무도 눈치채지 못하는 축이 아니면 spec 이 아니다.** 깨지면 즉시 드러나는 것(앱이 안 뜬다·테스트가 붉어진다·빌드가 실패한다)은 계약으로 박제할 필요가 없다.

## 양성 기준
- 시스템이 **무엇이어야 하는가** 를 평서문 선언. 반복 검증 가능. 시점·사건 의존 없음.

### 주제 우선순위
1. **사용자 관측 가능 동작** — 렌더 결과·상태 전이·HTTP/로그 계약. 1순위.
2. **토큰·설정 정합** — 기존 게이트로 검출되지 않는 **silent** regression 을 방어할 때만. **방어 대상을 §역할 에 명시**한다. 명시할 수 없으면 spec 이 아니다.

> 이 우선순위가 없던 기간에 green 21건 중 17건이 설정·토큰 정합이었고 제품 영역 귀속은 0건이었다. 실제 사용자 결함은 파이프라인 밖에서만 회수됐다.

## 처리
- **inspector**: 반려 시 `20.req/*` → `50.blocked/req/{slug}_reason.md`.
- **결함 신고성 req** 는 재현 서술을 이유로 반려하지 않는다. **위반된 불변식으로 재정식화해 흡수**한다.

예: ❌ "logsingle prod serial timeout 진단" / ✅ "logsingle 은 serial mode 에서 `LOG_SERIAL_TIMEOUT_MS` 초과 시 fail-fast".

## 수용 기준 문장

`## 수용 기준` 의 체크박스는 **현재 HEAD 에서 명령 1회로 rc 판정 가능**해야 한다. 판정 불가 문장은 체크박스로 두지 않는다.

| 부적격 부류 | 예 |
|---|---|
| 미래 사건 대기 | `차기 dep 이벤트 후 marker 플립` |
| 가정 주입 요구 | `favicon 삭제 회귀 시 exit 1` |
| 미측정 NFR | `< 100 ms` |
| 자명 명제 | `게이트는 read-only` |

부적격 항목은 삭제하지 말고 `## 참고` 하위 **`### 미측정·비판정 항목`** 으로 내려 평서문으로 박제한다. **단 '가정 주입 요구' 는 검출 방향을 보존한 채 게이트 도입 task 의 DoD 로 이관 표기한다** — 이관처 없는 강등은 금지.

## promote 조건

1. **§수용 기준 체크박스 전수 `[x]`.**
2. **§수용 기준의 측정 명령 전수 재실행 `rc=0`.** 명령 부재·실행 불가가 1건이라도 있으면 거부. notes 에 `promote-verify: N/N rc0`.
   - **다른 spec 의 green/blue 경로를 하드코딩하지 않는다** — promote 는 `mv` 라 경로가 깨진다. slug 로 도출한다: `f=$(find specs/30.spec/green specs/30.spec/blue -name '<slug>.md' | head -1); test -n "$f" || exit 2` (재개봉 중 두 브랜치에 동시에 있으므로 **green 을 먼저**).
   - §테스트 현황의 나머지 판정 명령도 실행하고 `diagnostics: M run, K failed` 를 박제한다. **실패는 승격을 막지 않으나 침묵은 금지** — 실패 명령을 §참고 에 평서문으로 남긴다.
3. **체크박스 0개 spec** 은 §동작 에 실존 테스트 파일 또는 `check:*` 식별자를 박제하고 planner 가 실존을 확인한 경우에만 가능.
4. **Must 게이트를 선언한 spec** 은 발화 채널 실경로(`scripts.check:*` / `.husky/*` / `ci.yml` / vitest 수집 경로) ≥1 을 박제하고 그 경로가 실재해야 한다. 채널 부재는 차단이 아니라 **채널 부착 task 발행**을 선행 조건으로 한다.

> 승격 4조건이 전부 문서 형식이던 기간에는 승격이 작성자의 포맷팅과 동치였다.
