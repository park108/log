# 격리 픽스처 — 게이트 0건 디렉터리 / TSK-20260825-38

`check-gate-seam-coverage.sh` 의 **무판정(exit 2)** 경로를 왕복 측정하기 위한 디렉터리다.
`check-*.sh` 를 하나도 담지 않는다 — glob 이 공집합을 내는 상태를 재현한다.

이 파일이 있는 이유는 git 이 빈 디렉터리를 추적하지 않기 때문이다. 디렉터리가 휘발하면
(K-3) 주입이 "경로 없음"(같은 exit 2 지만 다른 사유)으로 갈아타 방향이 흐려진다.

**여기에 `check-*.sh` 를 추가하지 말 것.**
